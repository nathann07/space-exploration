# Space Exploration (Step 1 Scaffold)

Initial implementation step for a lightweight browser 3D space exploration game.

## Included in Step 1

- Vite + Three.js project scaffold
- Core engine modules (renderer, scene, camera)
- Input abstraction layer
- Basic ship entity module
- Solar system root module
- HUD module
- Main loop and resize handling

## Run

```bash
npm install
npm run dev
```
